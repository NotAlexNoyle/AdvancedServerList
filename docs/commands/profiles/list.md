# `/asl profiles list`

## Permissions

Any of the following permissions will work:

- `advancedserverlist.admin`
- `advancedserverlist.command.profiles`
- `advancedserverlist.command.profiles.list`

## Description

Lists all currently loaded profiles.  
Each entry includes hover text displaying their priority, condition and if they are considered a valid profile by the plugin.
