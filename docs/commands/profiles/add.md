# `/asl profiles add <profile>`

## Permissions

Any of the following permissions will work:

- `advancedserverlist.admin`
- `advancedserverlist.command.profiles`
- `advancedserverlist.command.profiles.add`

## Arguments

| Argument    | Description                    |
|-------------|--------------------------------|
| `<profile>` | Name of the profile to create. |

## Description

Creates a new profile, using the default profile values.  
This requires [`/asl reload`](../reload.md) to be executed, to load the new profile.
