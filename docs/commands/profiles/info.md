# `/asl profiles info <profile>`

/// info | Only executable by players
///

## Permissions

Any of the following permissions will work:

- `advancedserverlist.admin`
- `advancedserverlist.command.profiles`
- `advancedserverlist.command.profiles.info`

## Arguments

| Argument    | Description                                |
|-------------|--------------------------------------------|
| `<profile>` | Name of the profile to receive info about. |

## Description

Lists currently set options for the profile.  
Every option can be clicked to receive the matching [`/asl profiles set ...`](set.md) command to edit it.
