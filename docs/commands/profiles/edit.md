# `/asl profiles edit <profile>`

/// warning | Only works on Paper Servers and for `v5.7.0-b1` and newer.
///

## Permissions

Any of the following permissions will work:

- `advancedserverlist.admin`
- `advancedserverlist.command.profiles`
- `advancedserverlist.command.profiles.edit`

## Arguments

| Argument    | Description                  |
|-------------|------------------------------|
| `<profile>` | Name of the profile to edit. |

## Description

Opens a Dialog, allowing you to edit the profile via its inputs.  
This requires [`/asl reload`](../reload.md) to be executed, to load the new profile.
